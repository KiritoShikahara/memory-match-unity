# Feature Specification: 画像カード神経衰弱モード

**Feature Branch**: `003-image-card-mode`

**Created**: 2026-11-24

**Status**: Approved

**Input**: "ユーザーが用意した画像フォルダのすべての柄で遊ぶ神経衰弱モードを追加"

## Clarify 決定メモ（2026-11-24）

| # | 項目 | 決定 |
|---|---|---|
| C1 | 画像の入手 | ユーザーが自分で用意しフォルダに置く。アプリも開発側も取得・加工しない |
| C2 | 置き場 | Editor: プロジェクト直下 `clock/`、ビルド: `StreamingAssets/clock/`。Inspector で変更可。`clock/` は git 対象外 |
| C3 | 枚数 | フォルダ内の jpg/jpeg/png 全部を各2枚（N種類→Nペア）。盤面は画面に入る最大サイズで自動配置 |
| C4 | ルール | 001 と同じ（当てたら継続、外したら交代、全部なくなるまで、ペア数最多が勝ち）。2〜4席・CPU 3段階 |
| C5 | 演出 | 002 の Celebration / SoundFx を流用（紙吹雪・連鎖・花火・効果音） |
| C7 | 拡大 | （2026-11-24 追加）右側に拡大パネル。最後にめくったカード、またはマウスを乗せた表向きカードを表示。パネルクリック/Z で全画面（高さいっぱい、元画像解像度）。全画面中はゲーム停止、クリック/Z/Esc で閉じる。裏向きのカードは拡大できない |
| C8 | 確認待ち | （2026-11-24 追加）2枚目をめくったら（当たり・外れとも、CPU の番も）「つぎへ」（クリック/Space/Enter）まで進まない。拡大パネルはマウスを乗せても変わらず、表向きカードをクリックしたときだけ切り替わる |
| C6 | 画像0枚 | 「画像がありません: <フォルダ>」と表示し、スタート不可 |

## User Scenarios & Testing

### US1 - フォルダの全柄で盤面を作る (P1)

1. **Given** ファイル名一覧, **Then** 拡張子 jpg/jpeg/png（大文字小文字問わず）だけを名前順で採用し、重複は除く
2. **Given** N種類, **When** 開始, **Then** 2N枚、各柄ちょうど 2枚
3. **Given** 枚数と表示領域, **Then** 全カードが領域内に収まり、カードが最大になる列数を選ぶ

### US2 - 対戦 (P1)

1. 2席以上（人/CPU）で交代し、全カードがなくなるまで続く。終了時に勝者表示

## Requirements

- FR-001 画像の選別と重複除去（US1-1）
- FR-002 ペア生成（US1-2）— 既存 MemoryGame / Deck を使う
- FR-003 自動レイアウト（US1-3）
- FR-010 自動テスト必須（EditMode: 選別・レイアウト / PlayMode: 一時フォルダの生成画像で通し対戦）。テストはユーザー画像に依存しない

## Success Criteria

- SC-001 `unity-cli test` EditMode / PlayMode 失敗0
- SC-002 `clock/` の全種類が盤面に2枚ずつ並ぶ
