# Feature Specification: タイトル・ゲーム選択とヘブンズゲート版

**Feature Branch**: `004-game-select-menu`

**Created**: 2026-11-24

**Status**: Approved

**Input**: "hevensgate の画像でヘブンズゲート版。タイトルの次にゲーム選択画面を追加し clock とヘブンズゲートを選べるように"

## Clarify 決定メモ

| # | 項目 | 決定 |
|---|---|---|
| C1 | 画像 | ユーザーが `hevensgate/` に置いた画像を実行時に読む。git 対象外 |
| C2 | 画面の流れ | 起動 → タイトル（クリック/Enter）→ ゲーム選択 → 各モード。各モードの「◀ ゲーム選択へ」で選択画面へ戻る（タイトルは飛ばす） |
| C3 | 選択肢 | 4×4 / ペアめくりパーティ / クロック神経衰弱（clock）/ ヘブンズゲート神経衰弱（hevensgate）。画像デッキは種類数を表示し、0枚なら選べない |
| C4 | 共通化 | 画像モードは ImageCardApp 1本。選んだデッキ（タイトル・フォルダ）で切替。拡大・確認待ち・演出は 003 と同じ |
| C5 | モード間ボタン | 既存のモード間直接リンクは廃止し「◀ ゲーム選択へ」に統一 |

## Acceptance

1. デッキ一覧に clock / hevensgate があり、フォルダ名は重複しない
2. デッキを選んで画像モードを開くと、そのデッキのフォルダとタイトルが使われる
3. ゲームから戻るとタイトルではなく選択画面が出る
4. Build Settings の先頭は Title シーン
5. FR-010: EditMode / PlayMode 自動テスト必須（ユーザー画像に依存しない）
