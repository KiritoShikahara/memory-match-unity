## User Scenarios & Testing

### User Story 1 - 18枚の盤面でペアを取る (P1)

1. **Given** 配置パターン, **Then** 6×3の18枚。キノコ・フラワー・スター各一約4枚、1UP・10コイン・20コイン各一約2枚（9ペア）
2. **Given** 8パターン, **Then** すべて異なり、どれも下段4〜6枚目（index 15,16,17）はキノコ・フラワー・スター
3. **Given** 1枚目が表, **When** 同じ景品をめくる, **Then** 2枚は取得済み、景品とポイントが手番の人に入り、手番は続く
4. **Given** 1枚目が表, **When** 違う景品をめくる, **Then** 不一致表示後に裏へ戻り、その人のミスが+1

### User Story 2 - 2ミス脱落で対戦する (P1)

1. **Given** 参加1席以下, **Then** 開始できない
2. **Given** 外した, **Then** 手番は次の「脱落していない」人へ
3. **Given** ミス2回, **Then** その人は脱落し以後飛ばされる
4. **Given** 全員脱落 または 全ペア取得, **Then** 終了。ポイント最多が勝者（同点は全員）
5. ポイント: 10コイン=10、20コイン=20、キノコ=30、フラワー=40、スター=50、1UP=100

### User Story 3 - 盤面の持ち越し (P1)

1. **Given** 取り残しありで終了, **When** 次の回（R）, **Then** 同じ配置で、取得済みカードは表のまま選べない
2. **Given** 全ペア取得で終了, **When** 次の回, **Then** 新しい配置パターンで全部裏から

### User Story 4 - CPU と画面 (P1/P2)

1. CPU は 001 と同じ CpuPlayer（見たカードだけ記憶、弱い/普通/強い）でめくる
2. 画面: 6×3盤面、各席のポイント・残りチャンス・獲得景品、オリジナルドット絵。001 の席設定画面からモード切替

## Requirements

- FR-001 配置は固定8パターン（US1-1,2）
- FR-002 一致で取得・継続、不一致でミス+1・交代（US1-3,4）
- FR-003 2ミス脱落、終了と勝者判定（US2）
- FR-004 盤面持ち越し（US3）
- FR-005 CPU は裏の絵柄を見ない
- FR-010 自動テスト必須（EditMode でルール、PlayMode で通し対戦）。unity-cli で実行
