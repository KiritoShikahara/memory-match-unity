# Feature Specification: 神経衰弱（2〜4人対戦・CPU戦）

**Feature Branch**: `001-memory-match`

**Created**: 2026-11-24

**Status**: Approved

**Input**: User description: "GitHub Spec Kit で SDD/TDD、unity-cli で Unity の実装とテストを回す 2D 神経衰弱。ペアでカードを取得でき、二人以上（CPU戦含む）で対戦できること。"

## Interview 決定メモ（2026-11-24・全項目推奨案で承認）

| # | 項目 | 決定 |
|---|---|---|
| Q1 | 人数 | 2〜4席。各席は「人」「CPU」「なし」を選ぶ。参加は2席以上。同一PCで交代 |
| Q2 | 手番 | 当てたら同じ人がもう一度。外したら次の人へ。全ペア取得で終了、ペア数最多が勝ち（同数は引き分け） |
| Q3 | 枚数 | 4×4 の16枚（8ペア） |
| Q4 | CPU | 弱い／普通／強いの3段階。表になったカードを確率で記憶。めくる前に0.6秒待つ。裏の絵柄は見ない |
| Q5 | 操作 | マウスクリック、矢印キー＋Space。Rで最初から（席設定は維持）。絵柄は色＋記号 |

## User Scenarios & Testing *(mandatory)*

### User Story 1 - ペアでカードを取得する (Priority: P1)

手番の人がカードを2枚めくり、同じ絵柄ならそのペアを自分のものとして取得する。

**Why this priority**: 神経衰弱の中核ルール。これがなければゲームにならない。

**Independent Test**: 1人分の手番だけでめくる・判定・取得を EditMode テストで確認できる。

**Acceptance Scenarios**:

1. **Given** 新しいゲーム, **When** 開始する, **Then** 16枚（8ペア）がすべて裏向きで、各絵柄はちょうど2枚、全員の取得ペア数は0
2. **Given** 同じシード, **When** 2回ゲームを作る, **Then** 配置は同一。異なるシードでは配置が変わりうる
3. **Given** 裏向きのカードが1枚表, **When** 同じ絵柄のカードをめくる, **Then** 2枚は取得済みになり手番の人のペア数が+1、手番は同じ人のまま
4. **Given** 裏向きのカードが1枚表, **When** 違う絵柄のカードをめくる, **Then** 2枚は表のまま「不一致表示」になり、確認（1.0秒）後に両方裏へ戻る
5. **Given** 表向き・取得済みのカード, **When** それを選ぶ, **Then** 何も起きない（同じカードを2枚目に選ぶことも不可）
6. **Given** 2枚が表で不一致表示中, **When** 3枚目を選ぶ, **Then** めくれない

---

### User Story 2 - 2〜4人で手番を回して対戦する (Priority: P1)

複数のプレイヤーが交代でめくり、全ペアが取られたら勝者が決まる。

**Why this priority**: 「二人以上で対戦」は必須条件。

**Independent Test**: 2人・3人の席構成で手番の移り方と勝者判定を EditMode テストで確認できる。

**Acceptance Scenarios**:

1. **Given** 2席以上, **When** ゲーム開始, **Then** 席1の手番から始まる
2. **Given** 手番の人が外した, **When** 不一致表示が終わる, **Then** 次の参加席へ手番が移る（最後の席の次は席1）
3. **Given** 最後の1ペアが取られた, **When** 判定する, **Then** ゲーム終了。ペア数最多の人が勝者、最多が複数なら引き分け（全員を勝者として表示）
4. **Given** 終了後, **When** カードを選ぶ, **Then** 何も起きない
5. **Given** 参加席が1以下, **When** 開始しようとする, **Then** 開始できない

---

### User Story 3 - CPUと対戦する (Priority: P1)

CPU席は自動でカードをめくる。強さは3段階で、見たカードだけを覚える。

**Why this priority**: 「CPU戦含む」は必須条件。1人でも遊べる。

**Independent Test**: CPUの選択ロジックを、固定乱数と観測済み情報で EditMode テストできる。

**Acceptance Scenarios**:

1. **Given** CPUの手番, **When** 0.6秒経つ, **Then** CPUは選択可能なカード（裏向き・未取得）を1枚めくる。2枚目も同様
2. **Given** 「強い」CPUがペアの2枚とも過去に表になったのを見ている, **When** CPUの手番, **Then** そのペアを取る
3. **Given** 「強い」CPUが1枚目をめくり、その相方の位置を見ている, **When** 2枚目を選ぶ, **Then** 相方を選ぶ
4. **Given** CPU, **When** 一度も表になっていないカードについて, **Then** 絵柄を知らない（裏の情報を使わない）
5. **Given** 記憶率: 弱い30%・普通70%・強い100%, **When** カードが表になる, **Then** その確率で位置と絵柄を記憶する

---

### User Story 4 - 席設定とやり直し (Priority: P2)

開始前に席ごとに「人／CPU（強さ）／なし」を選び、Rでいつでも最初からやり直せる。

**Acceptance Scenarios**:

1. **Given** 設定画面, **When** 開く, **Then** 既定は 席1=人、席2=CPU(普通)、席3・4=なし
2. **Given** プレイ中または終了後, **When** R を押す, **Then** 新しいシードで配り直し、全員のペア数0・席1の手番に戻る（席設定は維持）
3. **Given** プレイ中, **When** 矢印キーとSpace、またはクリック, **Then** カーソル移動とめくりができる（CPU手番中は人の入力を受け付けない）

### Edge Cases

- 不一致表示中の入力は無視する（3枚目はめくれない）
- CPU手番中の人の入力は無視する
- CPUのみの対戦（全席CPU）も可能。終了まで自動で進む
- 全員0ペアのまま終わることはない（全ペアが取られた時点で終了）

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 4×4・8ペアの山札をシード付きでシャッフルし、各絵柄をちょうど2枚にする
- **FR-002**: 手番の人は裏向き・未取得のカードだけをめくれる。1手番で2枚まで
- **FR-003**: 2枚の絵柄が一致したら取得済みにして手番の人のペア数を+1し、同じ人が続けてめくる
- **FR-004**: 不一致なら1.0秒表示した後に両方裏へ戻し、次の参加席へ手番を移す
- **FR-005**: 全ペア取得で終了し、最多ペアの人（複数なら全員・引き分け）を勝者として表示する。終了後はめくれない
- **FR-006**: 参加2〜4席。各席は人／CPU（弱い・普通・強い）／なし
- **FR-007**: CPUは表になったカードだけを記憶率（30%/70%/100%）で記憶し、0.6秒の間をおいて1枚ずつめくる
- **FR-008**: R で同じ席設定のまま新しいシードで初期状態に戻る
- **FR-009**: 絵柄は色と記号の両方で区別する。手番の人と各人のペア数を常に表示する
- **FR-010**: ゲームロジックとCPU思考は自動テスト（EditMode）を必須とし、unity-cli で実行する

### Key Entities

- **Card**: 位置・絵柄ID・状態（裏／表／取得済み）・取得者
- **Seat/Player**: 名前・種別（人／CPU＋強さ）・取得ペア数
- **Game**: 山札・参加者・手番・フェーズ（1枚目待ち／2枚目待ち／不一致表示中／終了）
- **CpuMemory**: CPUごとの「位置→絵柄」の記憶

## Success Criteria *(mandatory)*

- **SC-001**: US1〜US3 の受け入れシナリオがすべて EditMode テストで自動確認され、`unity-cli test` で全件合格
- **SC-002**: 人1＋CPU1、CPUのみ4人の対戦が Play モードで最後まで進み、勝者が表示される（verification.md に記録）
- **SC-003**: 1試合が3〜5分程度で終わる（16枚）

## Assumptions

- 範囲外: オンライン対戦、効果音、ランキング、ビルドした実行ファイル、外部アセット
- 同一PC・同一画面で交代して遊ぶ
- Unity 6000.6.4f1、IMGUI で描画（追加パッケージなし）
